# 📓 To-Do WEB

Um gerenciador de tarefas moderno, responsivo e fluido, focado em organização diária, produtividade e uma experiência visual minimalista.

---

## 🎯 Sobre o Projeto

O **To-Do WEB** é uma aplicação desenvolvida para a disciplina de projetos da faculdade. O sistema permite o gerenciamento completo de atividades diárias, utilizando o conceito de *Glassmorphism* (efeito de vidro fosco) na interface, suporte a modo escuro e controle inteligente de prioridades.

> 📝 **Nota de Planejamento:** O mapeamento de requisitos, escopo e arquitetura desta aplicação foram baseados no [Template Oficial da Disciplina](https://github.com/luiscarlosjunior/aulas-graduacao/blob/master/05-engenharia-software/disciplina-projetos/template-proposta-projeto.md).

---

## ✨ Funcionalidades Principais

* 🚀 **Autenticação Segura:** Login, cadastro e recuperação de senha com tratamento de erros em tempo real via Firebase Auth.
* 📅 **Seção "Tarefas de Hoje":** Carrossel horizontal responsivo com rolagem customizada para visualização rápida do dia.
* 🚦 **Níveis de Prioridade:** Identificação visual imediata (Alta, Média e Baixa) com estilização dinâmica via CSS.
* 🔄 **Filtros Inteligentes:** Separação e filtragem rápida de tarefas por status e categorias.
* ✔️ **Estado Concluído Absoluto:** Tarefas finalizadas ganham destaque verde e bloqueiam edições automaticamente.

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
* Ter o **Visual Studio Code** instalado.
* Instalar a extensão **Live Server** no VS Code.

### Passo a Passo
1. Clone o repositório ou baixe a pasta do projeto.
2. Abra a pasta raiz no seu **VS Code**.
3. Localize o arquivo `index.html` na árvore de arquivos lateral.
4. Clique com o botão direito sobre o `index.html` e selecione **"Open with Live Server"**.
5. O navegador abrirá automaticamente o projeto rodando na porta local (geralmente `http://127.0.0.1:5500`).
