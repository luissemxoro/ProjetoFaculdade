# 📓 To do WEB

Um gerenciador de tarefas moderno e fluido focado em organização diária e experiência visual.

---

## 🛠️ Tecnologias Utilizadas
* HTML5 e CSS3 (Glassmorphism)
* JavaScript Puro (ES6+ Modules)
* Firebase (Auth & Cloud Firestore)

---

## 💻 Como Rodar o Projeto

1. Abra a pasta do projeto no **VS Code**.
2. Certifique-se de ter a extensão **Live Server** instalada.
3. Clique com o botão direito sobre o arquivo `index.html` e selecione **"Open with Live Server"**.
